# 国庆主题作品征集

Next.js 投稿站点和服务器端管理后台。投稿文字保存在服务器数据目录的 JSON 文件中，图片和短视频原文件按流式方式写入服务器磁盘，不压缩。

## 本地开发

```sh
npm install
npm run dev
```

打开终端显示的地址。未配置管理员环境变量时，投稿功能可运行，管理后台会提示缺少配置。

## Docker / VPS 部署

1. 将项目放到 VPS，复制环境模板并修改密码与签名密钥：

   ```sh
   cp .env.example .env
   openssl rand -hex 32
   ```

   把生成的随机值填入 `ADMIN_SESSION_SECRET`，并将 `ADMIN_PASSWORD` 改成唯一强密码。不要提交 `.env`。

2. 默认数据目录是宿主机当前项目下的 `./data`，先创建并赋予容器 UID 1001 写权限：

   ```sh
   mkdir -p ./data
   chown -R 1001:1001 ./data
   docker compose up -d --build
   ```

   Compose 将宿主机 `DATA_PATH`（默认 `./data`）挂载到容器 `/app/data`。因此重建或删除容器不会删除投稿文件。可在 `.env` 中将 `DATA_PATH` 改为 VPS 上的绝对路径。

3. 站点仅绑定 VPS 的 `127.0.0.1:3000`，由 HTTPS 反向代理对外提供访问；代理也要允许与 `MAX_MEDIA_FILE_MB` 相符的请求体大小。至少 12 字符的 `ADMIN_PASSWORD`、至少 32 字符的 `ADMIN_SESSION_SECRET` 均为管理登录必填配置。

后台地址：`/admin`。管理员会话使用 HttpOnly、SameSite Strict Cookie，生产模式启用 Secure，8 小时过期。

## 服务器数据

- `data/submissions.json`：投稿文字、投稿人信息和附件清单。
- `data/media/`：已提交的图片、视频原文件。
- `data/uploads/`：尚未完成提交的临时附件；新投稿时会清理超过 24 小时的临时文件。
- 姓名、班级、微信号和标题必填。诗歌活动必须填写诗歌正文，字数不限；其他活动的文案选填。
- 活动一所有作品形式（包括“其他”）必须上传附件；短视频上传视频文件，其他形式上传图片。
- 图片单张最大 50 MB，摄影组图最多 10 张，其他图片形式最多 5 张；均保存原图，不压缩。短视频最长 2 分钟，默认最大 250 MB，可通过 `.env` 的 `MAX_MEDIA_FILE_MB` 调整视频上限（不改变图片的 50 MB 上限）。
- 图片与视频上传显示真实字节进度、当前文件和已传输大小；多图按本批总字节数计算整体进度。文件传输结束后等待服务器保存确认，收到成功响应才提示上传成功。
- 管理后台可以搜索、按活动筛选、点击图片查看大图、点击视频播放预览、下载原始附件、导出 JSON/CSV、删除单件或清空全部投稿。导出文件含文字和附件清单，不内嵌媒体二进制；请从对应作品卡片下载原文件。
- 联系方式属于个人信息；后台需使用强密码并部署在 HTTPS 下。定期备份整个 `DATA_PATH` 数据目录，并限制宿主机目录权限。

此版本以单个 Next.js 服务进程和本地持久化卷为目标。若需要多实例并发、复杂审核流或长期高并发，应将投稿记录迁移到 SQLite/PostgreSQL 等数据库，并为媒体使用专门的持久化存储。

## 主要文件

- `app/page.tsx`：公开投稿表单和服务器附件上传。
- `app/admin/page.tsx`：密码保护的投稿管理页面。
- `app/api/`：媒体上传、投稿写入、管理员认证和附件读取接口。
- `lib/server/storage.ts`：数据目录、原始附件与投稿文件读写。
- `compose.yaml`、`Dockerfile`：VPS 容器部署及持久化挂载。
